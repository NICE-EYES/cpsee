# PC Specs

Минималистичная утилита для просмотра сведений о железе компьютера, в духе CPU-Z.

## Возможности

- **Процессор** — модель, ядра и потоки, частоты, кэш, наборы инструкций, загрузка по каждому потоку в реальном времени.
- **Плата** — производитель и модель материнской платы, BIOS.
- **Память** — общий объём, схема заполнения слотов, параметры каждого модуля.
- **Диски** — физические накопители и разделы.
- **Видеокарта** — модель, драйвер, видеопамять; для NVIDIA — живые показатели (загрузка, температура, частоты, энергопотребление, вентилятор, PCIe) через `nvidia-smi`.
- **Оверлей** — небольшая панель поверх окон с выбранными показателями. Перетаскивается мышью, настраиваются набор и порядок метрик, цвета, прозрачность, размер шрифта и ориентация.
- **Экспорт** всех сведений в `.txt`.

Работает на Windows (PowerShell/CIM, `nvidia-smi`) и Linux (`/sys`, `lscpu`, `lsblk`, `dmidecode`).

## Скачать готовый .exe

Готовая сборка для Windows создаётся автоматически при каждом push:
вкладка **Actions** → последний запуск **build-exe** → раздел **Artifacts** → `PCSpecs-exe`.

## Запуск из исходников

Нужен Python 3.8+ с tkinter.

```bash
pip install -r requirements.txt
python pcspecs.py
```

На Linux tkinter ставится отдельно: `sudo apt install python3-tk`.

Вывести все сведения в консоль в формате JSON, без окна:

```bash
python pcspecs.py --dump
```

## Сборка .exe вручную (Windows)

Запустите `build_exe.bat`. Скрипт установит PyInstaller и `psutil`, соберёт программу,
и `PCSpecs.exe` появится рядом с ним.

## Файлы проекта

| Файл | Назначение |
| --- | --- |
| `pcspecs.py` | Вся программа |
| `pcspecs.ico` | Иконка приложения |
| `make_icon.py` | Генератор иконки (нужен Pillow, запускать не обязательно) |
| `build_exe.bat` | Сборка `.exe` на Windows |
| `.github/workflows/build.yml` | Автосборка `.exe` в GitHub Actions |

Настройки оверлея хранятся в `%APPDATA%\PCSpecs\settings.json` (Windows) или `~/.config/PCSpecs/settings.json` (Linux).
